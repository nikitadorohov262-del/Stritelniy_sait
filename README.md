# Сайт строительной компании

Готовый адаптивный сайт на чистом HTML/CSS/JS.

## Что внутри

- `index.html` — главная страница
- `css/style.css` — стили
- `js/script.js` — меню и форма
- `images/` — фотографии

## Как настроить под себя

1. Открой `index.html` в любом редакторе.
2. Замени все плейсхолдеры:
   - `[НАЗВАНИЕ]` / `[НАЗВАНИЕ КОМПАНИИ]` → название твоей компании
   - `[ТЕЛЕФОН]` → реальный номер (в формате +7...)
   - `[EMAIL]` → почта
   - `[ВАШ РЕГИОН]` → регион работы
   - `[НОМЕР]` → номер для WhatsApp/Telegram

3. При желании поменяй тексты в блоках услуг, преимуществ и «О нас».

## Форма заявок

Сейчас форма показывает alert. Чтобы заявки приходили на почту:

1. Зарегистрируйся на [Formspree](https://formspree.io) (бесплатно).
2. Создай форму, получи ID.
3. В `js/script.js` раскомментируй блок с fetch и подставь свой ID.

Или можно подключить Telegram-бота / другую интеграцию.

## Хостинг

Сайт полностью статический, подойдёт любой хостинг:

- **Бесплатно**: GitHub Pages, Netlify, Vercel, Cloudflare Pages
- **Платно**: любой shared-хостинг, Timeweb, Beget и т.д.

### Как залить на Netlify (самый простой способ):

1. Зайди на netlify.com
2. Перетащи папку `construction-site` в окно загрузки
3. Готово — получишь ссылку
